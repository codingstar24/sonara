# Changelog

All notable changes to **Sonara** are documented here.

## [1.0.0] - 2026-11-01

### Added
- **Spotify Desktop Design**: 3-column layout with collapsible navigation, 80px playback bottom bar, contextual drawer, and `#1ED760` accent.
- **Dual-Deck Audio Engine**: Gapless playback and crossfading (0–12s) powered by Web Audio API.
- **10-Band Graphic Equalizer**: Interactive SVG frequency curve, preamp gain, and acoustic presets.
- **60fps Real-Time Visualizer**: Frequency spectrum and waveform visualizer on HTML5 Canvas.
- **Synchronized LRC Lyrics**: Auto-scrolling lyrics with millisecond offset tuning and interactive editor.
- **Offline Recommendation Engine**: Context-aware Daily Mixes (1–6), "Picked for You", and listening stats.
- **Windows Desktop Standalone Executable**: Packaged with NSIS installer via Electron (`Sonara Setup 1.0.0.exe`).
- **Complete Folder & File Importer**:
  - Full folder and subfolder recursive scanning.
  - Automatic playlist generation per folder.
  - Automatic re-linking of previously loose tracks.
  - Drag-and-drop support for folders and individual audio files.
